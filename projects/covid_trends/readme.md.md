\## 📋 Project Overview Tracks and visualizes COVID-19 pandemic trends
including case numbers, recovery rates, and mortality statistics.

\## 🎯 Objectives 1. Monitor cumulative case trends 2. Calculate daily
new case rates 3. Track recovery and mortality rates 4. Identify peak
periods and trends

\## 📊 Dataset - \*\*Source:\*\* \`covid_data.csv\` - \*\*Features:\*\*
Date, Confirmed, Recovered, Deaths

\## 🔍 Key Findings 1. Pandemic progression timeline 2. Peak infection
periods 3. Recovery and mortality rate trends 4. Active case
calculations

\## 📈 Visualizations Generated - \`covid_trends.png\` - Overall trend
lines - \`daily_new_cases.png\` - Daily new case histogram -
\`rates_over_time.png\` - Recovery and mortality rates
