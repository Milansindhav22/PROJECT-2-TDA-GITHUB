\# Student Performance Analysis

\## 📋 Project Overview Analyzes student academic performance to
identify factors affecting success and areas for improvement.

\## 🎯 Objectives 1. Calculate overall pass/fail rates 2. Compare
performance across subjects 3. Examine the relationship between
attendance and marks 4. Identify at-risk students and high performers

\## 📊 Dataset - \*\*Source:\*\* \`student_performance.csv\` -
\*\*Features:\*\* Student ID, Subject, Marks, Attendance, Result

\## 🔍 Key Findings 1. Overall pass rate and subject-wise breakdowns 2.
Strong correlation between attendance and academic performance 3.
Subject difficulty rankings based on average scores 4. Attendance
threshold for passing likelihood

\## 📈 Visualizations Generated - \`pass_fail_rate.png\` - Overall
pass/fail distribution - \`subject_performance.png\` - Average marks by
subject - \`attendance_vs_marks.png\` - Scatter plot showing attendance
impact

\## 🚀 How to Run \`\`\`bash python analysis.py \`\`\`

\## 🛠️ Technologies - Python 3.x - pandas - matplotlib - seaborn - numpy
