\# Weather Data Analysis

\## 📋 Project Overview Analyzes weather patterns including temperature
trends, seasonal variations, and extreme weather events.

\## 🎯 Objectives 1. Track temperature trends over time 2. Identify
seasonal patterns 3. Analyze rainfall distribution 4. Detect extreme
weather events

\## 📊 Dataset - \*\*Source:\*\* \`weather_data.csv\` -
\*\*Features:\*\* Date, MinTemp, MaxTemp, AvgTemp, Rainfall, Humidity,
WindSpeed

\## 🔍 Key Findings 1. Temperature ranges and seasonal variations 2.
Rainfall patterns and rainy season identification 3. Frequency of
extreme weather events 4. Long-term climate trends

\## 📈 Visualizations Generated - \`temperature_trend.png\` -
Temperature over time with min/max range - \`seasonal_patterns.png\` -
Monthly average temperatures - \`rainfall_distribution.png\` - Histogram
of rainfall amounts
